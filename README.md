## Présentation

**Dakar Immo** est un site web de démonstration consacré à l’immobilier à Dakar. Il présente une maquette d’agence immobilière en ligne permettant de découvrir des exemples fictifs de villas, d’appartements et de terrains.

Le site propose notamment la recherche et le filtrage des annonces, le tri par prix, la gestion des favoris, la comparaison de biens et une carte interactive indiquant leurs quartiers. Les visiteurs peuvent consulter les détails d’une annonce et préparer une demande de renseignements ou de visite via WhatsApp.

> **Important :** ce site est un projet de démonstration. Les annonces, photos, prix, caractéristiques et disponibilités sont fictifs ou indicatifs et ne correspondent pas nécessairement à des biens réels. Le site ne constitue pas une offre immobilière.

## Technologies

- HTML
- CSS
- JavaScript
- Leaflet pour la carte interactive
